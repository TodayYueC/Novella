# Novella Full VN Example

This example is a lightweight, source-only visual novel project layout. It intentionally ships without engine binaries, export templates, or large art/audio assets.

## Structure

- `scripts/chapter_01.nvs`: complete story script using variables, localization, background, character, audio, choices, gallery, achievement, save, and route flow.
- `assets/README.md`: placeholder asset manifest showing the expected art/audio folders.

## 中文说明

这是一个轻量级、仅包含源码和占位说明的完整 VN 示例工程结构。仓库不会包含 Godot 引擎、导出模板或大型图片/音频资源。

目录：

- `scripts/chapter_01.nvs`：完整剧情脚本，覆盖变量、本地化、背景、角色、音频、选项、画廊、成就、存档和路线流程。
- `assets/README.md`：资源占位清单，说明推荐的美术和音频目录。
