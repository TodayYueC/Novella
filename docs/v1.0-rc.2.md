# Novella v1.0 RC.2

v1.0 RC.2 adds the first production-facing save/load UI foundation. The goal is to move save/load from manager-only behavior toward a reusable panel that projects can skin or replace.

## Included

- Version updated to `1.0.0-rc.2` across `Constants.VERSION`, `plugin.cfg`, release tests, and documentation.
- `NovellaSaveManager.list_slots()` for stable paged slot summaries.
- `NovellaSaveManager.get_slot_summary()` for occupied/empty slot metadata, title, summary, thumbnail, timestamp, and version fields.
- `addons/novella/state/ui/save_load_panel.tscn` and `save_load_panel_view.gd`.
- Save/load panel support for:
  - save mode and load mode,
  - paged slot display,
  - disabled load buttons for empty slots,
  - delete buttons for occupied slots,
  - overwrite/delete confirmation flow,
  - page change signals.
- Headless Godot tests for slot summaries, panel rendering, confirmation state, and emitted slot actions.

## Validation

Run the full local Godot test suite:

```powershell
.\scripts\test-godot.ps1
```

Run release validation:

```powershell
.\scripts\validate-release.ps1
```

## Compatibility

- Primary runtime: Godot 4.6.
- Compatibility target: Godot 4.3+ in the Godot 4 line.
- Godot 4.3, 4.4, and 4.5 compatibility remain targeted but unverified until those runtimes are available in the local or CI matrix.
