# Novella v2.0.0

`v2.0.0` is the official full PRD release of Novella.

## Highlights

- Promoted the completed v1.4-v1.7 full-PRD implementation line to the stable 2.0 release.
- Updated release validation to accept the 2.x stable line.
- Added final acceptance documentation.
- Kept the repository source-only: no Godot engine binaries, export templates, local PRD documents, local progress documents, cache folders, or generated archives are tracked.

## Verification

- Godot 4.6 headless tests pass.
- Release validation passes.
- Packaging produces `novella-2.0.0.zip`.
- Package inspection confirms forbidden local and binary paths are absent.
