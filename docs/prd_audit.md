## 中文审计摘要

这份公开审计只记录 PRD 完成状态，不提交本地需求文档原文。

已完成范围：

- 脚本引擎、解析器、AST、VM、命令系统。
- 分支、变量、表达式和流程控制。
- 文本表现、角色、背景、镜头、转场和特效。
- BGM、SE、语音绑定和 backlog 语音回放。
- 存档、读档、回滚、快进和已读状态。
- 运行时 UI、快捷菜单、UI 皮肤和反馈提示。
- 编辑器 dock、时间线编辑、实时预览和资源工具。
- 本地化、语言包、排版、资源覆盖、画廊、音乐室、路线图和成就。
- 调试面板、命令控制台、节点检查、性能面板和流程图。
- 按需加载、内存/FPS 基线、触控和手柄输入。
- 文档、示例、兼容矩阵和发布审计。
