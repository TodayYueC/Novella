# Novella v1.1.0

Novella v1.1.0 begins the v1.3 PRD track by making the default runtime playable instead of only script-driven.

## Added

- `NovellaVM.pause_on_text` for click-to-advance dialogue and narration.
- `advance_waiting(kind, line)` signal for UI integrations.
- `NovellaVM.advance()` and `NovellaVM.get_pending_advance()` helpers.
- `RuntimePlayer` scene and controller:
  - binds the default runtime managers,
  - shows the runtime stage,
  - pauses at dialogue and narration,
  - renders menu choices as buttons,
  - dispatches quick menu actions,
  - handles mouse/keyboard advance input.
- Runtime player tests for text advance, menu buttons, branch selection, and quick menu dispatch.

## Behavior

Existing synchronous `NovellaVM.run()` behavior remains the default. `RuntimePlayer` opts into `pause_on_text = true` and `auto_select_choices = false` to provide playable visual-novel flow.

Top-level dialogue and narration pause for player input. Menu branch content should jump to labels when the author wants follow-up lines to pause cleanly.
