# Novella v1.0.1

Novella v1.0.1 is a backward-compatible interaction polish release.

## Added

- `NovellaVM.auto_select_choices`, enabled by default to preserve the synchronous 1.0 behavior.
- `choice_waiting(choices, line)` signal for click-driven menu UI.
- `NovellaVM.get_pending_choice()` for inspecting a paused menu.
- `NovellaVM.choose(index)` for resolving the pending menu choice and continuing script execution.
- `NovellaVM.continue_run()` and `NovellaVM.is_finished()` helpers for step-style integration.

## Behavior

Existing calls to `Novella.run_script()` and `NovellaVM.run()` still execute synchronously and choose the first available menu option unless a `choice_strategy` is configured.

Projects that need player-driven menu buttons can set:

```gdscript
Novella.vm.auto_select_choices = false
```

The VM will then stop at menus, emit `choice_waiting`, and continue after `choose(index)` is called.
