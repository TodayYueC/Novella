# Novella v0.5 Alpha

v0.5 Alpha adds meta systems for long-form visual novel projects: localization, galleries, replays, and achievements.

## Included

- Localization manager with locale switching, fallback lookup, `$key` and `tr:key` text resolution, placeholder formatting, missing-key tracking, and save-state support.
- Gallery manager for registering, unlocking, locking, viewing, and listing CG/gallery items.
- Replay unlock support built on gallery entries with replay labels.
- Achievement manager with registration, progress, target unlocks, direct unlocks, hidden achievements, and condition evaluation.
- Meta commands:
  - `@locale locale`
  - `@language locale`
  - `@translation locale key text:value`
  - `@tr_var key to:variable_name`
  - `@gallery register|unlock|lock|view id ...`
  - `@replay unlock|view id label:start`
  - `@achievement register|unlock|progress|set id ...`
  - `@achieve ...`
  - `@meta_check`
- Basic UI views for language selection, gallery lists, and achievements.
- VM integration so dialogue, narration, and choices can localize `$key` and `tr:key` text.
- Save/restore integration through VM state providers.
- Editor timeline categorization for meta commands.

## Example

```text
@locale ja
Ryone: $line.greeting
menu:
    "$choice.unlock":
        @gallery unlock cg_school type:cg title:School asset:school.png
        @replay unlock intro_replay label:start title:Intro
        @achievement progress collector amount:1
```
