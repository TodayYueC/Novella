# v0.2 Alpha Presentation Core

This document records the v0.2 Alpha implementation. The goal of this milestone is to make the presentation layer executable and testable: dialogue printers, character/portrait state, background state, audio state, camera state, effects, and the commands that connect scripts to those systems.

## Added

- `NovellaTypewriterEffect`: CPS-based reveal timing, punctuation delays, reveal-all behavior, duration estimation.
- `NovellaRichTextParser`: converts Novella inline tags to Godot-style BBCode and extracts control tags such as `{w}`, `{cps}`, `{nw}`, and `{fast}`.
- `NovellaPrinterManager`: manages registered printer modes and dispatches dialogue/narration payloads.
- ADV/NVL state printers:
  - `adv`: single-line bottom dialogue payloads.
  - `nvl`: fullscreen accumulated page payloads.
- Minimal ADV/NVL Control scenes:
  - `addons/novella/presentation/ui/adv_printer.tscn`
  - `addons/novella/presentation/ui/nvl_printer.tscn`
- `@mode adv` / `@mode nvl`: switches the active printer mode at runtime.
- VM integration: dialogue and narration transcript entries now include a `presentation` payload when a printer manager is configured.
- `NovellaLayeredSprite`: layered portrait state and conditional layer filtering.
- `NovellaCharacterManager`: character registration, show/hide, move, emotion, focus, and side portrait state.
- `NovellaBackgroundManager`: background change, removal, scene change, environment state.
- `NovellaEffectManager`: screen/character effect registry and active effect state.
- `NovellaAudioManager`: BGM/BGS/SE/Voice channel state and volume controls.
- `NovellaCameraDirector`: camera move, zoom, rotation, presets, shake, and reset.
- `NovellaPresentationCommands`: script commands for v0.2 presentation systems.

## Design Notes

The printer managers are state-first services so they can be tested headlessly. The included Control scenes consume the same payloads and provide the runtime UI entrypoints. This keeps the VM contract stable while allowing later visual styling and animation refinements.

## v0.2 Commands

- Dialogue mode: `@mode`, `@nvl_clear`
- Characters: `@char`, `@char_remove`, `@char_move`, `@char_emotion`, `@char_effect`
- Backgrounds: `@bg`, `@bg_remove`, `@scene`, `@env`
- Audio: `@play_music`, `@stop_music`, `@play_se`, `@play_voice`, `@stop_voice`, `@ambience`
- Camera: `@camera`, `@camera_shake`, `@camera_reset`
- Effects: `@shake`, `@flash`, `@fade`, `@effect`
