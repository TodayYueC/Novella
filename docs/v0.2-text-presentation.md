# v0.2 Text Presentation Slice

This is the first v0.2 increment. It does not complete the full v0.2 Alpha milestone yet; it establishes the testable dialogue presentation contract that later UI scenes, portraits, audio, and camera systems can consume.

## Added

- `NovellaTypewriterEffect`: CPS-based reveal timing, punctuation delays, reveal-all behavior, duration estimation.
- `NovellaRichTextParser`: converts Novella inline tags to Godot-style BBCode and extracts control tags such as `{w}`, `{cps}`, `{nw}`, and `{fast}`.
- `NovellaPrinterManager`: manages registered printer modes and dispatches dialogue/narration payloads.
- ADV/NVL state printers:
  - `adv`: single-line bottom dialogue payloads.
  - `nvl`: fullscreen accumulated page payloads.
- `@mode adv` / `@mode nvl`: switches the active printer mode at runtime.
- VM integration: dialogue and narration transcript entries now include a `presentation` payload when a printer manager is configured.

## Design Notes

The current printers are `RefCounted` state objects rather than visual `Control` nodes. That keeps headless tests deterministic and avoids leaking CanvasItem resources. Later v0.2 work can add `.tscn` UI scenes that consume the same payloads without changing the VM contract.
