# Novella v1.0 RC.1

v1.0 RC.1 is the first release-candidate hardening pass after the v1.0 Alpha toolchain milestone. It focuses on runtime syntax coverage, version consistency, localization workflow, and release validation.

## Included

- Version updated to `1.0.0-rc.1` across `Constants.VERSION`, `plugin.cfg`, release manifest data, save payloads, and tests.
- Script parser support for `while ...:`, `endwhile`, `break`, and `continue`.
- VM execution support for guarded while loops, break/continue propagation, and inline commands attached to dialogue or narration lines.
- Basic command support for `@if condition then action` and weighted `@random label:weight ...` jumps.
- Localization CSV import/export APIs on `NovellaLocalizationManager`.
- Release validation coverage for the RC documentation and package manifest.

## Validation

Run the full local Godot test suite:

```powershell
.\scripts\test-godot.ps1
```

Run release validation:

```powershell
.\scripts\validate-release.ps1
```

## Compatibility

- Primary runtime: Godot 4.6.
- Compatibility target: Godot 4.3+ in the Godot 4 line.
- Godot 4.3, 4.4, and 4.5 compatibility remain targeted but unverified until those runtimes are available in the local or CI matrix.
