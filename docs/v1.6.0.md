# Novella v1.6.0

`v1.6.0` completes the meta systems, debugging, performance, and input phase of the full-PRD roadmap.

## Highlights

- Extended localization with typography rules, localized asset overrides, on-demand language packs, baseline plural forms, and split/merge helpers for long localized lines.
- Extended gallery/meta systems with music room entries and route map data.
- Extended achievements with progress summaries and notification queues for UI surfaces.
- Added `NovellaDebugPanelModel` for variable watch, VM trace, command console execution, node inspection, performance panel data, and visual flow graph panel data.
- Extended on-demand asset loading with windowed loading, audio streaming validation, and memory-state reports.
- Added `NovellaPerformanceBudget` for memory/FPS baseline capture and comparison.
- Extended input handling with touch and gamepad profile mappings plus input help metadata.

## PRD Coverage

This release covers a practical baseline for:

- LC-001 to LC-014: typography, localized assets, language packs, plural forms, and line split/merge support.
- MT-001 to MT-014: gallery, music room, route map, achievements, notifications, and meta-state reporting.
- DB-001 to DB-014: debug panels, command console UI data, node inspector data, performance panel data, and visual flow graph data.
- PF-001 to PF-012: on-demand loading, audio streaming validation, memory/FPS baselines, and loaded-asset reports.
- IN-001 to IN-008: touch and gamepad mapping metadata.

## 中文说明

`v1.6.0` 完成元系统、调试、性能和输入阶段。

主要新增：

- 本地化支持字体/排版规则、本地化资源覆盖、按需语言包、基础复数形式、长文本拆分与合并。
- 画廊系统增加音乐室和路线图数据。
- 成就系统增加进度汇总和 UI 通知队列。
- `NovellaDebugPanelModel` 提供变量观察、VM 追踪、命令控制台、节点检查、性能面板和可视化流程图数据。
- 按需资源加载支持窗口化加载、音频流式验证和内存状态报告。
- `NovellaPerformanceBudget` 支持内存/FPS 基线采集和比较。
- 输入处理增加触控和手柄映射，以及输入帮助元数据。
