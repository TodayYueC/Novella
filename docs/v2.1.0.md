# Novella v2.1.0

`v2.1.0` is the first post-PRD usability release. It keeps the `v2.0.0` runtime and release guarantees intact, then adds a practical non-code visual story editor inside the Godot editor dock.

## Highlights

- Added `NovellaVisualStoryEditorModel` for loading `.nvs` source into editable event cards.
- Added visual editor operations for creating, updating, moving, duplicating, deleting, copying, pasting, undoing, redoing, validating, previewing, and saving story events.
- Extended the `Novella` editor dock with `New`, `Save`, a visual timeline, and an `Inspector` tab.
- Added form-driven editing for labels, dialogue, narration, commands, background commands, character commands, audio commands, flow commands, and menu choices.
- Preserved inline commands when visual editor source is parsed and serialized.
- Added tests for visual editing, dock rendering, controller integration, save/reload behavior, and release validation.

## Visual Editor Workflow

1. Enable the `Novella` plugin in Godot.
2. Open the `Novella` dock.
3. Enter a `.nvs` path, such as `res://story/chapter_01.nvs`.
4. Click `New` to create a starter script, or `Analyze` to load an existing script.
5. Use the `Visual` tab to select, move, duplicate, copy, paste, or delete event cards.
6. Use the `Inspector` tab to choose an event type, edit fields, add a new event, or update the selected event.
7. Review generated script text in `ScriptPreview`.
8. Click `Save` to write the current visual editor script back to the path.

## Compatibility

- Primary runtime: Godot 4.6.
- Compatibility target: Godot 4.3+ in the Godot 4.x line.
- Godot engine executables, export templates, `.godot/`, `.godot_user/`, generated packages, and local requirement/progress documents remain excluded from Git and release packages.

## Validation

The release test suite covers:

- `NovellaVisualStoryEditorModel` editing APIs.
- Visual event serialization to valid `.nvs` source.
- Menu choice serialization with conditions and jump targets.
- Visual editor save and reload flow.
- `NovellaEditorController` visual editing methods.
- Editor dock rendering for visual timeline, Inspector preview, and diagnostics.
- Release manifest and package validation for `2.1.0`.
