# Novella v1.0 RC.5

v1.0 RC.5 adds the P0 foundation for visual timeline authoring inside the Godot editor.

## Included

- Version updated to `1.0.0-rc.5` across `Constants.VERSION`, `plugin.cfg`, release tests, and documentation.
- `NovellaTimelineEditorModel` for:
  - loading timeline events,
  - adding event blocks,
  - updating event data,
  - moving/reordering blocks,
  - duplicating and deleting blocks,
  - undo/redo,
  - serializing event blocks back into `.nvs` text.
- `addons/novella/editor/ui/timeline_editor_panel.tscn`.
- `NovellaTimelineEditorPanel` with visual/text mode toggle, event list, add, move, duplicate, and delete controls.
- Existing editor dock now includes a `Visual` timeline tab populated from script analysis.
- Headless tests for model editing, undo/redo, serialization, visual panel signals, and dock integration.

## Validation

Run the full local Godot test suite:

```powershell
.\scripts\test-godot.ps1
```

Run release validation:

```powershell
.\scripts\validate-release.ps1
```

## Compatibility

- Primary runtime: Godot 4.6.
- Compatibility target: Godot 4.3+ in the Godot 4 line.
- Godot 4.3, 4.4, and 4.5 compatibility remain targeted but unverified until those runtimes are available in the local or CI matrix.
