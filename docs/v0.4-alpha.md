# Novella v0.4 Alpha

v0.4 Alpha adds the first editor authoring workflow for Godot 4.6 while keeping the plugin compatible with Godot 4.3+ APIs where practical.

## Included

- Editor dock registered by `novella_editor_plugin.gd`.
- Script outline builder for labels, dialogue, narration, commands, menus, choices, and branches.
- Timeline model that categorizes story events into background, character, audio, camera, effects, interaction, flow, dialogue, narration, and choices.
- Diagnostics for parser errors, duplicate labels, missing jump/call targets, unknown commands, empty menus, empty lines, and empty choice actions.
- Template library for ADV scenes, NVL scenes, choice blocks, and character entrances.
- Asset index that classifies common script, scene, background, character, and audio paths.
- Headless tests for the editor models and dock rendering.

## Editor Dock

The dock appears as `Novella` in the Godot editor dock area when the plugin is enabled.

It can display:

- Outline rows grouped by script structure.
- Timeline rows ordered by script flow.
- Diagnostic counts and issue lines.
- Starter script templates.

Template activation copies the rendered template text to the clipboard.
