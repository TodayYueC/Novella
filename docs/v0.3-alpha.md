# Novella v0.3 Alpha

v0.3 Alpha adds the interaction and state layer on top of the v0.1 runtime and v0.2 presentation core.

## Included

- Choice evaluation with variable conditions, text interpolation, optional disabled choices, timeout defaults, and a minimal choice menu view.
- Save/load manager with memory storage for tests and JSON file storage for runtime use under `user://novella/saves`.
- Quick save, quick load, and autosave commands.
- Rollback snapshots with limits, prevent/allow controls, and fixed rollback boundaries.
- Skip manager with read/all/off modes and read-line tracking.
- Auto manager with delay, per-character timing, voice-wait support, and prevent/allow controls.
- Backlog manager for dialogue, narration, choices, capped history, and voice replay requests.
- Quick menu manager with configurable actions and a minimal quick menu view.
- VM state snapshots that include variables, transcript, call stack, and registered presentation/interaction providers.
