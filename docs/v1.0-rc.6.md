# Novella v1.0 RC.6

RC.6 is the release hardening pass for Novella 1.0.

## Added

- Script migration helper for `.nvs` files.
- Compatibility matrix helper for Godot 4.3 through 4.6+.
- Public API, command, and compatibility documentation.
- Release manifest and validation coverage for the new hardening files.

## Validation

- Godot headless unit tests cover migration, compatibility matrix validation, release manifest contents, and package filtering.
- Release validation confirms required files are tracked and forbidden local files remain excluded.

## Notes

- Godot 4.6 remains the primary verified runtime.
- Godot 4.3, 4.4, and 4.5 remain compatibility targets until local runtimes for those versions are installed and run through the same test suite.
