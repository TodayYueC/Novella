# Novella v1.2.0

`v1.2.0` expands the authoring workflow around script production, asset checks, timeline editing, and localization handoff. It keeps the runtime stable while adding tooling that can be used by editor docks, external scripts, or CI checks.

## Highlights

- Added `NovellaProductionWorkflow` as a single facade for project indexing, script analysis, timeline sessions, localization export/import, localized preview, and asset reference validation.
- Enhanced `NovellaTimelineEditorModel` with nested timeline import/export, search, replace, filtering, and round-trip `.nvs` serialization for menus, branches, and loops.
- Enhanced `NovellaAssetIndex` with richer asset metadata, command-aware suggestions, ID/path lookup, reference validation, and project summary output.
- Enhanced `NovellaLocalizationManager` with translator templates, missing-key merge support, and per-locale coverage reports.
- Added automated tests for production workflow analysis, localization preview, asset checks, timeline search/replace, release manifest coverage, and package validation.

## Production Workflow API

```gdscript
var workflow := NovellaProductionWorkflow.new()

var index := workflow.build_project_index([
    "res://art/backgrounds/school_day.png",
    "res://art/characters/ryone/uniform_happy.png",
    "res://audio/bgm/main_theme.ogg",
])

var analysis := workflow.analyze_script(source, "chapter_01.nvs", known_commands, index_paths)
var csv := workflow.export_localization_template([{"source": source, "file_path": "chapter_01.nvs"}], &"zh")
workflow.import_localization_csv(&"zh", "key,text\nline.greeting,Hello.\n")
var preview := workflow.preview_localized_source(source, &"zh", "chapter_01.nvs")
```

## Notes

- The release package still excludes Godot binaries, export templates, `.godot/`, `.godot_user/`, `dist/`, local PRD/progress documents, logs, and temporary files.
- The primary test target remains Godot 4.6, with API choices kept inside the Godot 4.3+ compatibility envelope.
- This version is a tooling milestone. The next planned step is deeper editor UI integration and broader v1.3.0 PRD coverage.
