# Novella v1.0 RC.3

v1.0 RC.3 completes the first pass of core save/settings UI requirements for the v1.0 P0 release line.

## Included

- Version updated to `1.0.0-rc.3` across `Constants.VERSION`, `plugin.cfg`, release tests, and documentation.
- Save slots now default to 64 total slots with 8 slots per page.
- Save metadata now fills playtime, formatted playtime, chapter, and timestamp when available.
- `NovellaSaveManager.page_count()` for default 8-page save/load screens.
- `NovellaSaveManager.autosave_if()` for configurable autosave triggers such as choice and scene transitions.
- `NovellaSaveManager.capture_thumbnail()` and `save_game_with_thumbnail()` for viewport thumbnail capture.
- `NovellaSettingsManager` for text speed, auto delay, volumes, fullscreen, skip-unread, and locale settings.
- `addons/novella/state/ui/settings_panel.tscn` and `settings_panel_view.gd`.
- `@settings` / `@config` commands for script-level settings changes.
- Quick menu `config` action now returns current settings state.

## Validation

Run the full local Godot test suite:

```powershell
.\scripts\test-godot.ps1
```

Run release validation:

```powershell
.\scripts\validate-release.ps1
```

## Compatibility

- Primary runtime: Godot 4.6.
- Compatibility target: Godot 4.3+ in the Godot 4 line.
- Godot 4.3, 4.4, and 4.5 compatibility remain targeted but unverified until those runtimes are available in the local or CI matrix.
