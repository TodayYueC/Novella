# Novella v1.4.0

`v1.4.0` advances the full-PRD roadmap by turning editor, asset, and UI foundations into production-oriented tools while keeping the addon GDScript-only and Godot 4.3+ compatible.

## Highlights

- Added `NovellaEditorPreviewSession` for live editor preview runs, manual text advance, choice selection, label jumping, variable watch snapshots, VM traces, and stage-state inspection.
- Added `NovellaResourceWorkbench` for asset catalog cards, character resource assembly, portrait layers, side portraits, voice/text-style metadata, background resources, and structural validation.
- Added `NovellaUISkinResource` for reusable ADV, choice, quick-menu, toast, and confirmation-dialog styles.
- Added `NovellaUIFeedbackManager` for confirmation requests, confirmation resolution, toast queues, and hide-dialogue state.
- Extended `NovellaProductionWorkflow` with preview-session, resource-report, and UI-default helpers.
- Extended `NovellaTimelineEditorModel` with copy/paste, collapse state, and event style metadata.
- Extended `NovellaQuickMenuManager` with visible/action configuration, ordering, state restore, and confirmation-required metadata.
- Fixed runtime-stage hide/unhide behavior so the active ADV/NVL printer is restored correctly.

## PRD Coverage

This release covers a practical baseline for:

- ED-018 to ED-024: live preview state, timeline production editing, event collapse, event style metadata, and preview navigation.
- ED-025 to ED-029: asset catalog cards, asset categorization, character/background resource assembly, side portraits, and resource validation.
- UI-001 to UI-012: UI skin/style resources, quick menu customization, confirmation prompts, toast-state management, and hide-dialogue behavior.

## Usage

```gdscript
var workflow := NovellaProductionWorkflow.new()
var session := workflow.create_preview_session(source, "chapter_01.nvs")
print(session.preview_state()["trace"])
session.advance()
session.choose(0)

var report := workflow.resource_report(asset_paths)
print(report["catalog"]["summary"])

var defaults := workflow.ui_production_defaults()
var skin: NovellaUISkinResource = defaults["skin"]
print(skin.style_for(&"quick_menu"))
```

## Notes

- The implementation remains script-first. C++ / GDExtension remains a future optimization option after profiling identifies a real bottleneck.
- Editor preview uses the same parser, command registry, VM, and runtime managers as the playable runtime.
- Godot engine binaries, export templates, `.godot/`, `.godot_user/`, local PRD files, and generated archives remain excluded from Git.

## 中文说明

`v1.4.0` 把编辑器、资源和 UI 基础推进到可用于制作流程的阶段。

主要新增：

- `NovellaEditorPreviewSession`：编辑器内实时预览、手动推进文本、选择分支、跳转标签、查看变量、追踪 VM 状态和舞台状态。
- `NovellaResourceWorkbench`：资源卡片、角色资源组装、立绘层、侧边头像、语音目录、文本样式、背景资源和结构校验。
- `NovellaUISkinResource`：ADV、选项、快捷菜单、toast 和确认弹窗的样式资源。
- `NovellaUIFeedbackManager`：确认请求、确认结果、toast 队列和隐藏对话框状态。
- `NovellaProductionWorkflow` 新增预览会话、资源报告和 UI 默认配置入口。
- 时间线编辑器支持复制、粘贴、折叠和事件样式元数据。
- 快捷菜单支持排序、显隐、配置和确认提示。
- 修复运行时舞台隐藏 UI 后恢复 ADV/NVL 当前显示层的问题。
