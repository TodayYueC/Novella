# Novella v1.0 RC.4

v1.0 RC.4 adds a reusable runtime presentation stage. It bridges the existing presentation managers and the visible Godot scene tree so a project can display script output without building every layer from scratch.

## Included

- Version updated to `1.0.0-rc.4` across `Constants.VERSION`, `plugin.cfg`, release tests, and documentation.
- `addons/novella/presentation/ui/runtime_stage.tscn`.
- `NovellaRuntimeStageView` for:
  - background state display,
  - visible character markers and focus dimming,
  - ADV/NVL printer scene switching,
  - effect overlay feedback,
  - audio status display,
  - camera position/zoom application,
  - manager signal binding.
- Headless tests for background, characters, ADV dialogue, effects, audio/camera state, and clearing behavior.

## Validation

Run the full local Godot test suite:

```powershell
.\scripts\test-godot.ps1
```

Run release validation:

```powershell
.\scripts\validate-release.ps1
```

## Compatibility

- Primary runtime: Godot 4.6.
- Compatibility target: Godot 4.3+ in the Godot 4 line.
- Godot 4.3, 4.4, and 4.5 compatibility remain targeted but unverified until those runtimes are available in the local or CI matrix.
