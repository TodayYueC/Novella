# Novella v1.3.0

`v1.3.0` starts the full-PRD completion baseline by adding developer tooling that connects the editor workflow, debugging workflow, route graph workflow, and on-demand asset workflow.

## Highlights

- Added `NovellaScriptLanguageService` for `.nvs` syntax tokens, symbols, command/label/asset completion, definition lookup, and reference search.
- Added `NovellaDeveloperTools` for variable watch/edit, VM trace snapshots, command console execution, node inspection, and performance snapshots.
- Added `NovellaFlowGraphBuilder` for route graph nodes, route edges, reachability checks, and unlock-state overlays.
- Added `NovellaOnDemandAssetLoader` for script asset reference collection, prioritized load plans, dry-run loading, and unused asset release.
- Extended `NovellaProductionWorkflow` with `language_report()`, `build_flow_graph()`, and `build_asset_load_plan()`.

## PRD Coverage

This release covers a practical baseline for:

- ED-030 to ED-034: script language service primitives for highlighting, completion, diagnostics, definitions, and references.
- ED-025, ED-026 to ED-029: asset validation and editor preview metadata surfaced through production workflow reports.
- DB-001 to DB-008: variable watch/edit, VM tracing, node inspection, performance snapshot, command console, and flow graph data.
- RT-001 to RT-005: route graph nodes, route edges, reachability, and unlock-state overlays.
- PF-005 and PF-007: on-demand asset queueing and stream-friendly audio plan metadata.

## Notes

- The implementation remains GDScript-only for easy addon installation and Godot 4.3+ compatibility.
- The on-demand loader defaults to dry-run mode so editor tooling and CI can validate plans without loading real art/audio assets.
- Godot engine binaries, export templates, `.godot/`, `.godot_user/`, local PRD files, and generated archives remain excluded from Git.
