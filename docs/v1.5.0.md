# Novella v1.5.0

`v1.5.0` completes the presentation, audio, and save-system phase of the full-PRD roadmap.

## Highlights

- Added `NovellaSceneRenderer` for deterministic render plans covering background layers, character layers, camera state, screen effects, transition steps, and character animation plans.
- Extended `NovellaCameraDirector` with queued camera animations and deterministic advancement.
- Extended `NovellaEffectManager` with shader registration, shader-pass metadata, effect timelines, and effect lifetime advancement.
- Extended `NovellaAudioManager` with an audio library, stream validation, voice-line registration, automatic voice-line resolution, voice playback, replay history, and backlog replay support.
- Extended `NovellaVM` so dialogue can automatically attach voice playback metadata and store voice ids in backlog entries.
- Extended `NovellaSaveManager` with save export/import and optional passphrase-based encrypted payload export/import.
- Extended `NovellaRollbackManager` with arbitrary rollback target listing and rollback by index, line, or metadata.
- Extended `NovellaSkipManager` with export/import helpers for persistent read-state tracking.

## PRD Coverage

This release covers a practical baseline for:

- PR-001 to PR-016: render plans, transitions, camera animation, screen effects, shader registration, and character layer presentation metadata.
- AU-001 to AU-012: BGM/SE/Voice stream metadata, validation, automatic voice association, voice replay, and playback history.
- SV-001 to SV-014: save import/export, optional encrypted payloads, rollback targets, and persistent read-state tracking.

## Usage

```gdscript
var audio := NovellaAudioManager.new()
audio.register_audio(&"main_theme", "res://audio/bgm/main_theme.ogg")
audio.register_voice_line(&"Ryone", 42, &"ryone_042", "res://audio/voice/ryone_042.ogg")
audio.play_voice_for_line(&"Ryone", 42)

var save := NovellaSaveManager.new()
save.enable_memory_storage(true)
save.save_game(&"slot_1", vm.snapshot_state(), {"title": "Scene 1"})
var encrypted := save.export_save(&"slot_1", true, "passphrase")
save.import_save(encrypted["text"], &"slot_2", "passphrase")
```

## 中文说明

`v1.5.0` 完成表现、音频和存档系统阶段。

主要新增：

- `NovellaSceneRenderer`：生成背景、角色、镜头、特效、转场和角色动画的确定性渲染计划。
- 镜头系统支持动画队列和按时间推进。
- 特效系统支持 shader 注册、shader pass 元数据、特效时间线和生命周期推进。
- 音频系统支持音频库、流验证、语音行绑定、自动语音解析、语音播放、播放历史和 backlog 语音回放。
- VM 在对话执行时可自动附加语音播放信息，并把 voice id 写入 backlog。
- 存档系统支持导出、导入和可选口令加密。
- 回滚系统支持按 index、行号和 metadata 回滚。
- 跳过/已读系统支持导出和导入持久化已读状态。
