# Novella v0.1 Alpha

Novella v0.1 focuses on the executable core: plugin registration, services, resources, Novella Script parsing, variable state, commands, and a small VM that can run a text scenario.

## Runtime

- Primary development runtime: Godot 4.6.
- Compatibility target: Godot 4.3+ within the Godot 4 line.
- Godot editor/runtime binaries and export templates must stay outside version control. This repository intentionally ignores `GodotEngine/`, editor caches, templates, and export artifacts.

## v0.1 Script Scope

Supported in this milestone:

- Dialogue: `Character: text`
- Narration: plain text
- Labels: `label name:`
- Flow: `jump`, `call`, `return`
- Branches: `if` / `elif` / `else` / `endif`
- Choices: `menu:` with guarded options
- Commands: `@var`, `@set`, `@flag`, `@wait`, `@jump`, `@call`, `@return`
- Text interpolation: `{variable}` and `{if condition ? true text : false text}`

Later milestones add rendering, audio, editor UI, save/load, rollback, localization, gallery, and release tooling.
