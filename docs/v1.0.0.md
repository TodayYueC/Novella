# Novella v1.0.0

Novella v1.0.0 is the first stable source release of the Godot 4 visual novel / GalGame plugin.

## Included

- Runtime core: `.nvs` lexer, parser, AST, expression evaluator, variable system, command registry, VM, labels, jumps, calls, returns, menus, inline commands, `if`, `while`, `break`, and `continue`.
- Presentation core: ADV/NVL printer state, rich text conversion, typewriter timing, background, character, effect, audio, and camera managers.
- Interaction and state: choices, save/load, quick save/load, autosave triggers, rollback, skip, auto mode, backlog, quick menu, settings manager, save/load panel, and settings panel.
- Meta systems: localization, CSV import/export, gallery, replay unlocks, achievements, and meta commands.
- Editor tools: dock integration, outline builder, diagnostics, templates, asset index, timeline model, visual timeline editor model, and timeline panel.
- Runtime UI foundation: reusable runtime stage for background, character markers, ADV/NVL output, effects, audio status, and camera state.
- Release tooling: validation script, package script, GitHub Actions release check, release manifest, compatibility matrix, and migration helper.

## Compatibility

- Primary verified runtime: Godot 4.6.
- Compatibility target: Godot 4.3 and newer in the Godot 4 line.
- Godot 3.x is outside the v1.0 support target.
- Godot 4.3, 4.4, and 4.5 remain compatibility targets pending local runtime matrix verification.

## Validation

- `scripts/test-godot.ps1`
- `scripts/validate-release.ps1`
- `scripts/package-addon.ps1`

The generated package is written to the ignored `dist/` directory. Godot engine binaries, export templates, `.godot/`, `.godot_user/`, local requirement/progress documents, logs, caches, and generated packages are excluded from version control.
